## 🎯 Question Pattern Analysis

### Question Types

1. **MCQ (Multiple Choice)**: ~60%
2. **MSQ (Multiple Select)**: ~20%
3. **NAT (Numerical Answer)**: ~20%

### Difficulty Distribution

- **Easy**: 30% (Basic concepts, definitions)
- **Medium**: 50% (Application, analysis)
- **Hard**: 20% (Complex problem-solving)

### Common Question Formats

1. **Code Output**: Given code, find output
2. **Complexity Analysis**: Find time/space complexity
3. **Algorithm Correctness**: Which algorithm works?
4. **Construction**: Build tree/graph from given data
5. **Comparison**: Compare different approaches
6. **Optimization**: Find optimal solution

## 💡 Preparation Strategy

### Phase 1: Topic Mastery (Months 1-8)
For each topic:
1. Study theory and concepts
2. Solve all previous year questions on that topic
3. Practice additional problems
4. Revise and make notes

### Phase 2: Year-wise Practice (Months 9-12)
1. Solve complete year papers (2015-2025)
2. Time yourself (3 hours per paper)
3. Analyze mistakes
4. Identify weak areas

### Phase 3: Mock Tests (Months 13-15)
1. Take full-length mock tests
2. Mix questions from different years
3. Focus on speed and accuracy
4. Final revision
