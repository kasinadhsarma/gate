# Arrays & Strings

## 📌 Topic Overview

Arrays and Strings are fundamental data structures that form the basis of many algorithms. This topic has **HIGH** weightage in GATE.

## 🎯 Key Concepts

### Arrays
- One-dimensional and multi-dimensional arrays
- Array manipulation and traversal
- Searching in arrays (linear, binary)
- Sorting arrays
- Subarray problems
- Kadane's algorithm (Maximum subarray sum)

### Strings
- String manipulation
- Pattern matching (KMP, Rabin-Karp)
- String reversal and rotation
- Palindrome problems
- Anagram problems
- Longest common substring/subsequence

## 💡 Important Patterns

1. **Two Pointer Technique**
   - Used for: Pair sum, removing duplicates, reversing
   - Time: O(n), Space: O(1)

2. **Sliding Window**
   - Used for: Subarray problems, substring problems
   - Time: O(n), Space: O(1)

3. **Prefix Sum**
   - Used for: Range sum queries
   - Time: O(1) query after O(n) preprocessing

4. **Hashing for Strings**
   - Used for: Anagrams, pattern matching
   - Time: O(n), Space: O(n)

## 📊 Complexity Analysis

| Operation | Array | String |
|-----------|-------|--------|
| Access | O(1) | O(1) |
| Search (unsorted) | O(n) | O(n) |
| Search (sorted) | O(log n) | O(n log n) |
| Insert at end | O(1) | O(n) |
| Delete | O(n) | O(n) |
